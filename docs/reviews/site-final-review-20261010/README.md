## 本轮修正

- 2个产品目录和22个分类页补上邮件草稿，与WhatsApp使用相同正文，带入类别、公开页面网址及姓名／公司提示。说明客户须在应用中自行发送；图片和图纸可在应用中附加。
- 目录样式增加内容哈希版本，避免浏览器或服务器缓存保留旧的双按钮布局。
- 首次询盘从姓名／公司和所需产品开始，尺寸、数量、目的地等可后补；分类选型区标题改为产品选型，去掉泛化的OEM／ODM标签。
- 搜索无结果时增加询盘入口；说明搜索包含产品详情页内的型号和尺寸，照片表示注明的样品，具体选型查看型号表。例如DN100可找到含该尺寸的报警阀系列，而DN150实拍不改标为DN100。
- 中、英、阿首页的询盘标题统一为先说明所需产品。首页制造介绍此前已经简化，本轮复核保留准确的生产信息归属及证书范围说明。
- 水雾及水幕喷头英阿页把“已确认的买家规格”“替换照片”等内部措辞改为产品规格及实际结构、图库介绍。
- NRS闸阀的空泛“待确认”认证行改为按所选型号索取适用文件，没有新增产品认证。英阿同步，原始基准和确切审阅差异保留。
- 卷盘配件FHR-012和BP-020不再把“connection to be confirmed”当成连接参数，显示本语言的索取连接详情提示；原始来源缺项仍内部保留。
