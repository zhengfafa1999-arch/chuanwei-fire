## 实际范围

使用 Chrome 对 https://chuanweifire.com/ 线上现有版本进行手机视口模拟，抽查 360×800、390×844、430×932。不是实体手机/Safari 测试，也不是 185 个页面在全部尺寸上的逐页验收。

检查页面：首页、产品目录、About、Contact、文件/证书页、隐蔽式喷头详情，以及阿拉伯文文件页和目录。线上仍是旧版本：目录显示 184 个产品条目/10 类，About 没有本地新增的 8 张厂房照片。不能把线上结果当成本地新版已验收。

本地 file:// 页面被浏览器 URL 安全策略拒绝读取；没有绕过限制访问本地文件。仅通过正常文件读取对照本地 CSS/HTML。

Chrome 自动翻译英文页，用户允许在当前标签页显示原文，但工具不能访问工具栏的翻译面板，本轮未成功切回稳定英文显示。因此英文页面的持续视觉检查主要是在自动中文翻译后的状态，不能声称英文长文本排版已完整复验。阿拉伯文页保持 ar/rtl，进行了原文检查。

## 检查时提出的建议（后续已获同意，见末尾实施记录）

1. **联系表单字号偏小**：实测输入框/下拉框/文本域文字为 12px。本地 `css/public-pages.css` 的 `.form label` 为 12px，控件继承该字号，最新版仍存在同一设置。建议手机输入内容提高至 16px，标签可另设 13–14px。属于可读性优化，未声称发生真实手机故障。
2. **规格表缺少横向滑动提示**：隐蔽式喷头表格宽 820px，窄屏滚动容器宽 319px，容器 overflow-x 为 auto，未撑宽整页。本地也有 `.pdp-table-wrap`，未找到左右滑动提示。建议增加手机可见的滑动提示或边缘渐变。未进行实体手机手势测试，不将其判作表格不能滚动。
