# 官网客户展示复查

日期：2026-10-09。检查对象为当前工作区的官网内容、源资料和175个本地生成公开页面；线上首页仅作抽查。当前修改未部署，不能将本地通过等同于线上已经更新。

本轮检查覆盖首页、产品目录、11个分类的英阿页面、71个产品详情的英阿页面，以及 About、联系、文件页面。中文仅覆盖已有首页。检查公开文字、型号表、图片用途、证书展示、询盘、内部链接及代表页面的排版；不代表已独立验证每项产品性能或证书当前登记状态。

- 用户本轮明确确认首页机加工、批量生产、仓库和厂区4张图片均为冠亚工厂实拍。保留制造能力展示，不将其误判为AI图；确认及文件哈希见 [manufacturing-confirmation.json](manufacturing-confirmation.json)。此确认不涵盖包装示意图。
- 3张证书图片所载 ISO 标准、编号、日期及产品覆盖范围与首页一致：ISO 9001到期2028-12-08；ISO 14001、ISO 45001到期2028-05-12。这里只核对证书图片与网页，未声称已查询认证登记或完成有效性审核。
- CHUANWEI FIRE作为冠亚工厂出口品牌，实物带GUANYA / 冠亚标识可以保留，About已有说明。
- 71对英阿产品页共334行型号表按单元格核对数字一致，见 [language-tables.json](language-tables.json)。已确认的 Z＝直立、X＝下垂，以及筒式泡沫喷头图3上喷、图4下喷保持。

构建使用 `npm --ignore-scripts run build`，跳过PDF生成。构建、SEO、多语言导航、静态资源、搜索、产品图片及补充规格检查通过。手机和桌面检查结果、截图、PDF未变核验及本轮候选包信息见 [validation-summary.json](validation-summary.json)。
