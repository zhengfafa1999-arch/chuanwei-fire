## 本轮修改

- 全站175个公开页面的产品菜单先展示11个分类，默认收起；一次展开一个分类，保留188个产品入口和原网址，增加每个分类的直接入口。分类按钮高度至少44px；手机 Escape 关闭后焦点回到菜单按钮。
- 24个目录系列、115个配置的英文和阿拉伯文名称改为产品类型、已记录的接口及型号。移除仅靠颜色、表面外观区分的标题；无法确认接口标准的产品仍使用准确结构描述。型号逐项列出，不推造型号范围。
- 原始 `catalog-expansion.json` 未改，图片、来源、选项和锚点保留。旧名称作为当前配置的搜索别名，避免别名或型号继承到其他配置。具体前后对照见 `name-changes.json`。
- 修正 HS-020 搜索误命中 UHS-020：型号前缀以字词边界开始，保留部分型号查询。DN / DN空格、组合筛选、每页12项及 URL 状态恢复继续使用原机制。
- 菜单 CSS、菜单脚本和搜索脚本使用文件内容哈希版本，避免浏览器继续沿用旧资源。原页面保留检查只允许这三项已明确版本化的资源变化；原始结构和媒体基准未改。
- 用户确认“样品收费，起订量按产品确定”，在 About 和 Contact 英阿四个页面加入两项采购 FAQ。没有新增 OEM 数量、免费样品、运费政策或交期天数。
- 用户明确要求同时删除 About 的出口品牌关系说明，英阿两页已删除该段及标题。保留证书范围说明、证书原件和实物标识；内部事实确认历史不删除。不新增工厂注册中文全称。
