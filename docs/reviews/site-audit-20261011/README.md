## 不应放进公开网站的文件

仓库含原始资质图册（其中有银行开户类内容）、历史网页、报价/审核资料、源文件和工作记录。这些应留在内部。当前发布包沿用显式白名单，排除了 `docs/`、`tools/`、`site-src/`、临时文件、原始图册、PDF 下载文件及历史 `guanya_original` 网页。

不要把整个 `D:\code\ai-code` 目录当作服务器网站根目录上传。该风险针对部署方式；本次没有证据表明这些内部文件已经在线泄露，也未连接线上服务器检查。

若以后部署新版，需同时从服务器移除已撤销的 `assets/downloads/standard-response-fire-sprinklers-en.pdf`，仅移除入口不能撤回服务器上仍存在的文件。此次未操作服务器。
