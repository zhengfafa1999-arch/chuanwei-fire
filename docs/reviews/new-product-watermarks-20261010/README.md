用户要求检查并给新加图片补水印。原工具只遍历 `products/`，后续图片位于 `assets/products/`，因此未被处理。本轮扩展现有工具，沿用 `CHUANWEI FIRE` 与 `CHUANWEI FIRE · chuanweifire.com` 文字样式。

## 完成范围

- 为 135 个新增产品图片尺寸版本补齐水印，包括新喷头、隐蔽式喷头、阀组件、水流指示器、压力开关、电磁阀、装饰配件及已复用实拍。
- 当前公开页面使用其中 126 个文件；72 张在用大图逐一通过四张联系表复核。每张原图至少有品牌及网址文字，适合的位置增加浅色斜向品牌文字。
- 水印文字放在空白处，避开产品、铭牌、玻璃球、螺纹、实物标记；没有裁剪、放大或重绘产品。135 个文件尺寸与内部原件一致，最大文件 201601 字节。
- 更新 38 张受影响的分类缩略图。38 是本轮更新量，全站缩略图清单仍有 197 项。
- 英阿及中文首页使用带图片内容哈希的版本链接，主图、图库切换、放大图、下方照片及 `srcset` 一致，避免继续显示缓存中的旧图。
- 更新发布图片哈希及加工记录，保留源文件原有哈希、来源记录与内部未加水印副本。6 张已被白底图替换的旧装饰件素材保留历史字节，当前公开页面没有引用它们。

## 后续新增图片

依次执行 `python tools/apply-product-watermarks.py --new-assets`、`node tools/generate-catalog-thumbnails.mjs --keep-stale`、`npm --ignore-scripts run build`。工具依靠 `site-src/_data/product-watermarks.json` 防止重复处理；原件在 `.watermark-backups/site-assets-original/` 内部保存，不进入公开发布包。已记录图片内容发生变化时工具会停止，需要核对新来源后再更新记录。
