## 结论

现有阿里资料能支持多个官网系列的内容完善，不只喷头。最有价值的是同一资料包里的用户确认记录、参数证据表、型号表及原始照片；生成图片用来检查最终显示内容。部分参数已经在官网上，应补来源及图片，避免重复新增。

本轮先完成全目录收集和复用分流，随后按用户“能用、能补充的写入官网”要求，将证据范围明确的资料补入 21 个产品页、37 个配置、183 个规格字段，英阿同步，另补 4 张原始实拍。已生成本地网页，尚未部署；未逐张审核全部图片或逐页复核扫描检测报告。详见[本批官网修改清单](website-update.md)。

## 已解决和需继续处理的冲突

1. **标准喷头方向已解决**：用户于 2026-10-09 确认“以官网为准：Z＝直立，X＝下垂”。已写入官网源数据的内部确认记录，公开型号表保持现有正确对应。阿里 68°C 包中反向的型号映射、文案和参数图仍保留原件，列为后续修图/文案纠正需求；不能直接上传这些旧图。
2. **DN250 文件夹错配**：`ZSXDF7-Q-DN250-对夹式消防信号蝶阀` 清单及输出实际引用 DN150。该包先隔离；不能仅用目录名确认产品口径。
3. **BS-750 重量**：官网约 20 kg；阿里档案提示约 20/32 kg 冲突。列为待称重/配置核验，不判定哪一个错误。
4. **水雾、水幕的铜体与不锈钢**：不同供货配置，不能作为同一型号的材质纠错。保留原铜制页面，新增独立不锈钢配置后再对应参数。
5. **官网 ASTM 材料对应表述**：雨淋/干式阀现有文案含 `QT450-10 / ASTM A536 65-45-12`；本次阿里证据未确认该国际材料等同性，雨淋包还明确省略 ASTM 等同说法。本批已删除雨淋/干式阀公开文案中的 ASTM 自动等同部分，保留 QT450-10。国际等同性仍待原始材质文件核对。
6. **同系列报告适用范围**：ZSFC100/150 不覆盖 200；ZSFZ 法兰证据不自动覆盖沟槽；新款预作用不自动继承旧款参数；新照片不自动继承官网同系列旧参数。
7. **同名不同用途**：`65-16K-65` 水泵接合器与室内双阀消火栓分别建档；接口和水路不同，不能依工厂型号字符串合并。

## 后续官网需求如何使用

- 每个系列开始前先检索这份汇编中的“确认”“证据”“缺项”文档，复用已确认材料；只向用户索取该配置确实缺少的资料。
- 官网采用真实产品图配合可检索、可翻译的 HTML 规格/型号表；阿里长图作为文案参考，优先返回原图，避免把信息只能读在图片上。
- 每个字段绑定具体型号、方向、温度、材料、接口、测量定义及证据文件。工作压力、试压、爆破、供水范围和表盘量程分开。
- 只做同单位的算术换算，保留原值；不把 PN 数字变成国外认证，不把型号数字自动变成 DN/K 值，不把流量计算变成实测。
- 用户已授权把全系列可用资料直接补入现有官网，本批按明确的配置证据完成补充。后续完整页面重做和独立系列验收仍按计划推进。
- 最新总目录、准确制造主体关系、真实包装/检测/出货内容仍应按原计划核对。阿里生成场景不能充当工厂、安装项目或出货证据。
