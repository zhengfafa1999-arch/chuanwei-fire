# MIG-209 消防喷头分类多语言收尾

八个已发布喷头产品系列均可通过英文和阿文分类页进入对应语言详情。分类页早已采用共享模板，本轮只补充验收约束，不重做页面、不改变图片和产品参数。

## 防回退检查

- 固定现有八类产品及顺序，检查 16 张双语卡片、32 个图片/文字入口。
- 分类入口必须指向同语言产品，不能保留英文回退标记。
- 浏览器按实际链接匹配产品，不依赖路由登记顺序与卡片顺序一致。
- 检查首页、总目录、分类、详情、互切、刷新、后退及三个页脚返回入口。

## 验收结果

快速全站构建通过：73 个发布页面、53 个共享生成页面、20 个待迁移英文详情页。

文件预览与本地 HTTP 预览分别通过：

- 58 个代表页面/视口组合。
- 292 个全站响应式及 LTR/RTL 检查。
- 110 个语言切换、返回及产品交互场景。

六种喷头模板的所有图库图片、说明、放大、关闭、箭头、滑动及型号区域均纳入本轮回归。另复核阿文分类桌面/手机与首页截图；本轮未改变首页或图片。
