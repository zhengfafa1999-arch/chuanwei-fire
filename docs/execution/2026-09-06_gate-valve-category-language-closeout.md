# MIG-505 消防闸阀分类页语言入口收尾

消防闸阀分类页继续使用全站共享分类模板。本轮只收尾多语言入口和定向验证，不改动产品参数、图片或版式。

## 覆盖范围

- 法兰信号闸阀
- 沟槽信号闸阀
- 暗杆闸阀（NRS）
- 明杆闸阀（OS&Y）

英文分类页 `products/消防阀门.html` 与阿文分类页 `ar/products/gate-valves/index.html` 均保留四款产品及原顺序。每张卡片的图片和文字入口均进入相同语言的对应详情页，不再显示英文回退标识。
