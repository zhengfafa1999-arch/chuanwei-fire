# 首页本地多语言路径修复

本轮只恢复内容并修复语言路径。MIG-905 已按用户要求暂停，不再核对或修改产品参数。

## 用户反馈与复现

用户原话：“我怎么感觉你给改坏了，首页显示都有问题了，你先不要核对参数正确性问题了，只弄多语言切换就行了”。没有收到具体异常区域截图，因此不声称已解释用户看到的所有显示问题。

诊断分类：configuration（页面相对路径）；已复现路径缺陷的置信度高。无服务器或 Docker 环境改动。

内容清理前的首页模板同时使用 `<base href="../">` 和 `../css/site-navigation.css`、`../assets/js/site-navigation.js`、`../apple-touch-icon.png`。中文和阿文首页本地打开时，浏览器会解析到站点目录之外；HTTP 根目录预览会掩盖重复上级路径。页内 `#products` 也会受 base 影响离开当前语言首页。

浏览器回归在修复前复现：`Error: desktop//zh/index.html has 1 broken images.`。检查模板及实际解析路径确认 Logo、外链导航样式及脚本具有同一错误。

## 已执行

- 恢复 `5d4d5f6` 对首页、关于页、分类图和产品参数文案的改动，保留此前多语言模板、SEO、导航与响应式功能。
- 移除内容审核的构建拦截和 `tools/validate-content.mjs`。删除的检查可从 Git 历史恢复，原产品图片和历史报告未删除。
- 首页不再使用 base；图片、背景、预览图片和分类链接均按当前语言页面位置生成路径。页头继续使用公共导航模板。
- 添加 `--file-preview` 验证方式，补充首页资源加载、页内按钮不换语言、阿文产品卡片跳转检查。未改变产品内容及布局。
- 迁移计划改为沿用现有英文内容，仅处理翻译、共享模板和语言切换。既有未知项保持原文，不擅自增加或删改结论。
