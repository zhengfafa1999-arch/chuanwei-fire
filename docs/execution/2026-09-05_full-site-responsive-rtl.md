# MIG-904 全站响应式与 RTL

## Summary

全站 64 个正式页面已完成响应式与文字方向统一。英文和中文页面明确使用 LTR，阿拉伯文页面明确使用 RTL；共享模板页与 29 个尚未迁移的英文详情页都受同一套页面方向、全局页头和小屏布局规则约束。

## Deliverables

### 明确的语言与方向

- 每个正式页面均具有与路由一致的 `lang` 和 `dir`。
- 阿拉伯文页面的文档计算方向为 RTL，英文与中文页面为 LTR。
- 旧英文详情页由幂等构建步骤自动补齐方向，不需要逐页手工维护。
- 社交按钮使用逻辑方向定位，桌面 RTL 页面自动出现在正确一侧。

### 四档响应式布局

全站逐页覆盖以下宽度：

- 桌面：1440×900
- 平板：768×1024
- 手机：390×844
- 紧凑手机：320×568

桌面显示完整导航；其余宽度显示可展开菜单。320 像素下隐藏页头询价按钮，保留品牌、语言和菜单入口。页面内允许横向查看的规格表与缩略图轨道保持局部滚动，不造成整个页面横向溢出。

### 小屏内容遮挡修复

原有产品详情页的社交按钮在 320 像素宽度下会覆盖标题或正文。现在小屏时按钮改为页面末尾的横向静态按钮组，桌面和平板仍保留悬浮展示；浏览器校验会确认紧凑视口下不再使用固定定位。

### 自动验证

浏览器验证逐页检查：

- 文档语言、声明方向与实际计算方向；
- 响应式 viewport；
- 整页横向溢出和页头边界；
- 图片加载失败；
- 输入框、下拉框、文本域和按钮越界；
- 桌面导航展示及平板/手机菜单展开；
- 小屏社交按钮定位；
- 语言切换、刷新、返回和未翻译产品回退。
