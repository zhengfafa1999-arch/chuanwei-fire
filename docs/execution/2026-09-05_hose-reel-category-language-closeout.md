# MIG-305 软管卷盘分类页多语言收尾

软管卷盘分类页继续使用全站公共分类模板。本轮不修改产品参数、图片或版式，只把四款已迁移卷盘纳入严格的分类入口和完整浏览器回归。

- RIA 25 消防软管卷盘
- 直流水枪消防软管卷盘

英文和阿拉伯文分类页均保持上述四款及原有顺序。每张卡片的图片与文字链接都进入同语言详情页，分类页不再出现英文回退标记。
