# MIG-705 室外消火栓分类页多语言收尾

本轮只收尾室外消火栓分类的多语言入口与自动化约束，不重新核对或修改产品参数、图片和版式。

## 分类范围

- 英文分类：`products/室外消防栓/室外消防栓.html`
- 阿文分类：`ar/products/outdoor-hydrants/index.html`
- 产品：BS 750、法式、印尼式和俄式室外消火栓
- 共用目录数据：`site-src/_data/productDirectory.js`

## 实施内容

- 增加室外消火栓分类的严格列表校验，固定四款产品及原有顺序。
- 校验每张卡片的图片与文字链接都进入相同语言的对应详情页。
- 校验英阿两套页面均为正式详情入口，不得恢复英文回退标记。
- 保留分类页现有内容、图片和版式。
