**状态：** 进行中
**目标：** 将正式站点剩余手写页面逐个迁移为“共享模板 + 产品数据 + 语言文案 + 自动生成页面”的结构。

## 每个产品的固定执行流程

1. 以现有英文页面为内容基线，记录图片、参数、文案和布局。
2. 只处理翻译、共享模板和语言对应链接；不要求用户重新提供英文页已有的产品资料。
3. 保持非语言内容不变；原有未知项照原文保留，不新增技术结论。
4. 建立一份中立产品数据源，不在语言页面中重复维护参数。
5. 建立英文和阿拉伯文文案；以后增加语言只增加文案数据。
6. 用共享详情页模板生成两个语言地址。
7. 更新所属分类页、首页入口、语言对应地址、站点地图和内部链接。
8. 执行数据校验、构建、断链检查及浏览器点击测试。
9. 每个产品单独提交，确认无误后再开始下一个。

- 参数、既有未知项、图片和英文文案保持迁移前内容；不将翻译工作扩展成资料审核。
- 图片文件和所属产品不变，语言版路径正确。
- 英文和阿拉伯文由同一模板与同一产品数据生成。
- 两种语言保持相同页面结构，阿拉伯文正确使用 RTL。
- 分类入口、语言切换、返回链接和直接网址均可用。
- 自动构建、数据验证、断链检查和浏览器测试通过。
- 独立 Git 提交已完成，未获授权时不推送、不部署。
